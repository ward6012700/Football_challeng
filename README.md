# تحدي الكرة العالمية — نسخة السيرفر v2 (قابلة للنشر)

نسخة مستقلة من اللعبة مربوطة بسيرفر حقيقي: كل اللاعبين يلعبون على نفس
السيرفر، وترتيب الشهر مشترك بين الكل. مبنية من النسخة الثابتة المصدّرة
(900 سؤال) مع كل التعديلات التي طلبها ورد.

**الموقع الحي حالياً:** https://football-challeng.onrender.com/ (نسخة v1).
هذه النسخة v2 بديلة مباشرة (drop-in) — نفس الـ API ونفس الأسعار ونفس الميزات،
مع إغلاق ثغرات التلاعب بالكوينز والنقاط. انظر CHANGES.md للتفاصيل الكاملة.

- **ترتيب شهري عالمي مشترك** + ترتيب عام، وأول 3 بنهاية الشهر يتأهلون للنهائي على **جائزة 50 دولار**.
- **متجر كوينز بالأسعار المخفّضة**: تلميح 50:50 = 15، حياة إضافية = 30، إعادة محاولة = 20،
  وقت إضافي = 15، تخطي إضافي = 25، إزالة إعلانات = 150، ألقاب وألوان 75–500.
- **باقات شحن**: 200 بـ $0.49، 650 بـ $1.49 (+7%)، 1400 بـ $2.99 (+15%)، 2500 بـ $4.99 (+23%، الأوفر).
  **لا دفع داخل الصفحة** — الطلب عن طريق مراسلة المطوّر على إنستغرام.
- **الصوت شغال** (موسيقى + مؤثرات، مع فك القفل عند أول ضغطة، وزر كتم).
- **لا قسم أرباح ولا أرقام دخل** في أي مكان عام.
- المطوّر الوحيد الظاهر: **ورد المحمود @ward.6012700**.

## الجديد في v2 — الأمان أولاً

- **النقاط والكوينز بيد السيرفر:** السيرفر يتحقق من كل نتيجة (100–200 نقطة لكل إجابة صحيحة، كوينز مكتسبة بحدود الاقتصاد الحقيقي للعبة، مدة مباراة منطقية) ويتجاهل أي رصيد يرسله المتصفح. محاولة إرسال `coins: 999999` لا تعطي شيئاً.
- **كل عمليات الشراء من السيرفر:** عناصر المتجر والألقاب تُشترى عبر `/api/shop/buy` مع تحقق من الرصيد وخصم فعلي — لا شراء محلي بعد الآن.
- **ثغرة «الشحن التجريبي» أُغلقت:** زر الباقة صار «اطلب عبر إنستغرام 📩» ويفتح مراسلة ورد — لا كوينز مجانية.
- **المزامنة (`/api/sync`) لا تمنح شيئاً:** تقبل فقط نقصان المخزون (استخدام عنصر) وتفعيل لقب مملوك أصلاً.
- **أسماء نظيفة:** تُحذف وسوم HTML من أسماء اللاعبين (حد 20 حرفاً).
- **حدّ لمعدل الطلبات:** 300 طلب/دقيقة عام، 12 إرسال نتيجة/دقيقة، 5 تسجيلات/دقيقة لكل IP.
- **تصميم محسّن:** أزرار إجابة أكبر للمس، حالات ضغط وتركيز أوضح، صف «أنت» في الترتيب أبرز.

## API

- `GET /api/health` — حالة السيرفر وعدد اللاعبين
- `GET /api/packs` — باقات الشحن
- `GET /api/leaderboard?type=monthly|global` — الترتيب (أول 25)
- `GET /api/player?id=...` — بيانات لاعب
- `POST /api/register` `{name}` / `POST /api/rename` `{playerId, name}`
- `POST /api/submit` `{playerId, score, correct, total, coinsEarned, coinsSpent, durationMs}` — نتيجة مباراة؛ السيرفر يتحقق من كل قيمة ويحسب الكوينز بنفسه (حقل `coins` المرسل يُتجاهل)
- `POST /api/sync` `{playerId, inv, titles, activeTitleId}` — مزامنة المخزون والألقاب فقط (لا كوينز)
- `POST /api/shop/buy` `{playerId, item}` — شراء من المتجر (يخصم من السيرفر)؛ الألقاب بصيغة `title:<id>` مثل `title:sniper`

**يُمسح عند إعادة نشر جديدة** — للاستمرارية الحقيقية لاحقاً يلزم قرص
دائم (Render Disk) أو قاعدة Postgres.

## حدود معروفة (v2)

- **الإحياء بـ 30 كوينز:** حالة قديمة لم تُلمس — خصم الـ 30 كوينز عند الإحياء يتم محلياً فقط، ونقاط ما بعد الإحياء لا تُرسل للسيرفر. لا تؤثر على الترتيب ولا تفتح ثغرة غش. انظر PROJECT_PROGRESS.md.
- **العملاء القدامى:** من لديه صفحة v1 مخزنة في المتصفح (5 دقائق) سيشتري محلياً حتى تتحدث صفحته — السيرفر الجديد يرفض تثبيت تلك المشتريات.
- **لا دفع حقيقي للباقات:** الشحن بالمراسلة على إنستغرام كما في v1.
- **لا قاعدة بيانات حقيقية:** التخزين ملف JSON — يكفي لآلاف اللاعبين، وليس لمئات الآلاف.
