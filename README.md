# تحدي الكرة العالمية — نسخة السيرفر (قابلة للنشر)

نسخة مستقلة من اللعبة مربوطة بسيرفر حقيقي: كل اللاعبين يلعبون على نفس
السيرفر، وترتيب الشهر مشترك بين الكل. مبنية من النسخة الثابتة المصدّرة
(900 سؤال) مع كل التعديلات التي طلبها ورد.

## ما فيها

- **900 سؤال** (225 بكل فئة: كأس العالم، دوري الأبطال، الدوريات، الأساطير — 871 صعب).
- **تسجيل لاعب بالاسم** (زر «سجّلني بالترتيب العالمي») وحفظ النقاط والكوينز على السيرفر.
- **ترتيب شهري عالمي مشترك** + ترتيب عام، وأول 3 بنهاية الشهر يتأهلون للنهائي على **جائزة 50 دولار**.
- **متجر كوينز بالأسعار المخفّضة**: تلميح 50:50 = 15، حياة إضافية = 30، إعادة محاولة = 20،
  وقت إضافي = 15، تخطي إضافي = 25، إزالة إعلانات = 150، ألقاب وألوان 75–500.
- **باقات شحن**: 200 بـ $0.49، 650 بـ $1.49 (+7%)، 1400 بـ $2.99 (+15%)، 2500 بـ $4.99 (+23%، الأوفر).
  **لا دفع داخل الصفحة** — الطلب عن طريق مراسلة المطوّر على إنستغرام.
- **الصوت شغال** (موسيقى + مؤثرات، مع فك القفل عند أول ضغطة، وزر كتم).
- **لا قسم أرباح ولا أرقام دخل** في أي مكان عام.
- المطوّر الوحيد الظاهر: **ورد المحمود @ward.6012700**.

## الملفات

| ملف | ماذا |
|---|---|
| `server.js` | السيرفر (Node.js بدون أي مكتبات خارجية) + API |
| `public/index.html` | اللعبة كاملة (مبنية من النسخة الثابتة) |
| `public/questions.json` | بنك الأسئلة الـ900 بصيغة JSON |
| `server-sync.js` | كود ربط اللعبة بالسيرفر (مضمّن في index.html) |
| `build.py` | يعيد بناء `public/index.html` من النسخة الثابتة المصدّرة |
| `render.yaml` | إعداد النشر على Render |
| `data/db.json` | قاعدة اللاعبين (تُنشأ عند أول تشغيل؛ فارغة عند الإطلاق) |

## API

- `GET /api/health` — حالة السيرفر وعدد اللاعبين
- `GET /api/packs` — باقات الشحن
- `GET /api/leaderboard?type=monthly|global` — الترتيب (أول 25)
- `GET /api/player?id=...` — بيانات لاعب
- `POST /api/register` `{name}` / `POST /api/rename` `{playerId, name}`
- `POST /api/submit` `{playerId, score, correct, total, coinsEarned, coins}` — نتيجة مباراة
- `POST /api/sync` `{playerId, coins, inv, titles, activeTitleId}` — مزامنة الرصيد والمخزون
- `POST /api/shop/buy` `{playerId, item}` — شراء من المتجر (يخصم من السيرفر)

## النشر العام — الخطوة المتبقية (تحتاج حساباً)

**لا يوجد رابط عام بعد.** كل خدمات الاستضافة المجانية تحتاج حساباً، ولا يوجد
حساب متصل هنا. الطريق الصحيح هو **Render (الخطة المجانية)** — سيرفر Node
عادي، بدون بطاقة بنكية:

1. **صديق ورد في ألمانيا** (أو ورد نفسه بإيميل وكلمة سر جديدين، لا غوغل)
   ينشئ حساباً مجانياً على https://render.com — لا يحتاج بطاقة.
2. ينشئ مستودعاً على GitHub ويرفع إليه محتويات هذا المجلد
   (`server-deploy/` كاملاً).
3. في Render: New → Web Service → يربط مستودع GitHub → Runtime: Node →
   Start Command: `node server.js` → Create. الرابط يكون مثل:
   `https://football-challenge-server.onrender.com`
4. يشارك ورد هذا الرابط مع اللاعبين بدل الرابط الثابت.

ملاحظات عن الخطة المجانية في Render: السيرفر ينام بعد فترة خمول (أول فتح
يأخذ ~30–60 ثانية)، وملف `data/db.json` يبقى بين إعادات التشغيل لكنه
**يُمسح عند إعادة نشر جديدة** — للاستمرارية الحقيقية لاحقاً يلزم قرص
دائم (Render Disk) أو قاعدة Postgres. لا تستخدموا الرابط الثابت القديم
للإطلاق إذا أردتم الترتيب المشترك — هو نسخة غير مربوطة بالسيرفر.

## حدود معروفة

- السيرفر يثق برصيد الكوينز النهائي الذي ترسله اللعبة بعد المباراة
  (لا يوجد نظام مكافحة غش) — كافٍ للإطلاق، وليس لمنع التلاعب المتعمد.
- الأنفاق المؤقتة (localtunnel / Cloudflare quick tunnel) لا تعمل من هذا
  الجهاز: localtunnel.me غير قابل للوصول، وCloudflare يفشل بسبب بروكسي
  الخروج. لا تعتمدوا عليها للإطلاق.
- Vercel غير مناسب لهذه النسخة (سيرفر Node دائم + ملف قاعدة بيانات)،
  وRender هو الخيار الصحيح.
